
# 🏎️ Badger Grand Prix

A 3D arcade kart racer: badgers versus the nation's college mascots on a Madison-themed circuit.

## 🚀 Run

Serve this folder with Python 3:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000 to play.
